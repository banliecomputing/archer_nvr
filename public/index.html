Engine Live View & MediaMTX

MediaMTX memproses live stream WebRTC tanpa beban CPU transcoding di Node.js (Ultra Low Latency <0.5 detik). Konfigurasi otomatis menetapkan HLS ke port :8880 dan API ke :9997 untuk menghindari konflik port 8888.

Default: 8889 (Port WebRTC / WHEP MediaMTX).
Biarkan kosong untuk otomatis menggunakan IP STB saat ini.
Format URL Pemutar: http://[IP_STB]:8889/[camera_id]
